# Weather Studio

Нативное приложение для macOS с атмосферными эффектами поверх рабочего стола. Написано на Swift, AppKit и SwiftUI. Это самостоятельный прототип с функциями, вдохновленными KoiArt, без использования его исходников и графических материалов.

## Возможности

- Шесть эффектов: снег, дождь, сакура, листья, светлячки и звездопад.
- Накопление снега, лепестков и листьев на доступных верхних границах окон.
- Разлет частиц при движении окна и взаимодействие с курсором.
- Дождевые брызги, метеоры с искрами и светлячки, собирающиеся возле неподвижного курсора.
- Прозрачный слой, пропускающий клики к приложениям под ним.
- Настройки интенсивности, ветра и скорости, управление из строки меню Mac.
- Интерактивный предпросмотр с перетаскиваемым условным окном.
- Шесть оригинальных пейзажей: сохранение PNG, установка обоев и возврат прежнего фона.
- Экономный режим, пауза при сне экрана и на полноэкранных приложениях.

## Требования

- Mac с Apple Silicon.
- macOS 14 или новее.
- Apple Command Line Tools с компилятором Swift и SDK macOS.

Если инструменты разработчика еще не установлены:

```sh
xcode-select --install
```

Внешние библиотеки, аккаунт и подключение к сети для работы приложения не нужны. Полный Xcode для сборки не требуется.

## Сборка и запуск

После клонирования репозитория перейдите в его папку и выполните:

```sh
zsh build.sh
open "build/Weather Studio.app"
```

Скрипт создает приложение в `build/Weather Studio.app`, подписывает его локальной ad-hoc подписью и запускает встроенную самопроверку. Готовая папка `build/` не включается в Git.

Для повторной самопроверки:

```sh
"build/Weather Studio.app/Contents/MacOS/WeatherStudio" --self-test
```

Проверка запускает симуляцию всех шести эффектов, проверяет лимит частиц, накопление и паузу, отрисовывает эффекты и обои, затем выводит результат в терминал. Для этой проверки нужен активный графический сеанс macOS с доступным экраном.

## Использование

1. Выберите эффект в панели приложения.
2. Нажмите «Включить», чтобы показать его поверх рабочего стола.
3. Настройте интенсивность, ветер и скорость.
4. В разделе «Обои» сохраните изображение или установите его на все экраны. Фон меняется только после нажатия соответствующей кнопки.
5. Для полного выхода выберите «Завершить Weather Studio» в меню приложения. Закрытие панели оставляет значок в строке меню Mac.

При запуске эффекты на рабочем столе выключены. Выбранный эффект и настройки сохраняются на этом Mac. Адреса прежних обоев сохраняются перед первой заменой, чтобы их можно было восстановить.

## Доступ к окнам и приватность

Приложение использует доступную геометрию окон через публичные API macOS. Оно не записывает содержимое экрана, не сохраняет снимки окон и не отправляет данные в сеть.

macOS может ограничивать сведения об окнах других приложений. Если эффекты не оседают на их границах, в настройках Weather Studio есть кнопка «Настроить доступ к окнам…». Она запрашивает системное разрешение «Запись экрана» только по нажатию пользователя. После изменения доступа может понадобиться перезапуск приложения. Разрешение не гарантирует одинаковое поведение всех окон и версий macOS.

## Ограничения версии 0.1

- Это первая рабочая версия, а не полное воспроизведение коммерческого приложения.
- Пока нет автозапуска, автообновлений, обработки пользовательских фотографий и сборки для Intel.
- Накопление на окнах и Dock зависит от доступной геометрии. Поддерживается горизонтальный Dock, если его границы доступны.
- Несколько мониторов предусмотрены в коде, но первоначальная проверка выполнена на одном экране.
- Восстановление динамических обоев macOS может вернуть только изображение.
- Приложение имеет локальную подпись и не нотарифицировано для распространения.

## Структура проекта

```text
Sources/
  main.swift              Панель, меню, настройки и жизненный цикл
  WeatherView.swift       Частицы, физика и отрисовка эффектов
  WindowTracker.swift     Геометрия видимых окон
  WallpaperRenderer.swift Генерация фоновых изображений
Info.plist                Метаданные приложения
build.sh                  Сборка, локальная подпись и самопроверка
```
